# Security policy

Do not report vulnerabilities in public issues. Report it privately through GitHub: open a draft advisory at <https://github.com/stanleyHayes/ghanacalendar/security/advisories/new>. Include the product name, affected version or URL, reproduction steps and impact. Do not include live credentials or sensitive personal data.

Production releases require dependency review, secret scanning, least-privilege credentials, rate limits where applicable, security headers, auditability for privileged changes, and a tested rollback path.

A dedicated `security@digitalghana.dev` mailbox is not configured yet — the domain currently has no mail routing — so GitHub private vulnerability reporting is the only monitored channel. This file will be updated if that changes.
